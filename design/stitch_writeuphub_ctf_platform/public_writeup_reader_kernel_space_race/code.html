1. Challenge Synopsis & Target

tag

During the 48-hour sprint of DEF CON 32 Qualifiers, Kernel Space Race emerged as the premier binary exploitation challenge. Players were provided a custom patched Linux kernel image executing under QEMU with complete hardening defenses: CONFIG_SLAB_FREELIST_HARDENED, SMEP, SMAP, KASLR, and page table isolation (KPTI) fully active.

info
Target Environment Specification

Tested against Linux Kernel 6.6.21-generic with SMEP, SMAP, and KASLR enabled. No custom modules were loaded; the bug resides directly in the asynchronous submission queue logic.

2. Reconnaissance & Surface Analysis

tag

Reversing the provided diff file against upstream kernel tree revealed an intentional race window in io_uring/io_uring.c during request cancellation handling. Specifically, an asynchronous task could be marked for immediate destruction via unregister ring while an inflight vector request still held a stale reference in the submission ring cache.

warning
Volatile Exploit Warning

Exploiting this io_uring race condition will panic the host kernel if thread synchronization misses the microsecond scheduling slot. Always execute inside dedicated virtualization boundaries.

3. Vulnerability: Double-Free Race Condition

tag

Because lock acquisition order was inverted between the SQPOLL worker thread and user-space ring termination, calling close(ring_fd) concurrently with an unbounded read caused the request structure in kmalloc-128 to be placed back onto the CPU slab freelist twice.

4. Bypassing KASLR via Leaked Heap Pointer

tag

With a controlled double-free in kmalloc-128, we allocate a seq_file structure immediately followed by an overlapping socket buffer. Reading from the sequence file gives us an untouched kernel text address (single_open symbol), computing the kernel base offset in under 20 milliseconds:

from pwn import *
import os, struct, threading

def trigger_uaf_leak(vuln_ring):
    # 1. Spray kmalloc-128 cache with seq_operations structures
    spray_fds = [os.open("/proc/self/stat", os.O_RDONLY) for _ in range(128)]
    
    # 2. Overlap double-freed descriptor via async read buffer
    leak_raw = os.read(vuln_ring, 8)
    ktext_single_open = struct.unpack("<Q", leak_raw)[0]
    
    # 3. Calculate kernel text base address
    kernel_base = ktext_single_open - 0xffffffff814205a0
    log.success(f"Leaked single_open: {hex(ktext_single_open)}")
    log.success(f"KASLR Base Slide : {hex(kernel_base)}")
    return kernel_base

5. Crafting the Arbitrary Write Primitive

tag

Once KASLR is defeated, we pivot our freelist corruption primitive to overwrite the modprobe_path symbol. By abusing the second free, we insert our target address into the next free pointer slot, causing the subsequent slab allocation to yield a pointer directly inside kernel global variables.
