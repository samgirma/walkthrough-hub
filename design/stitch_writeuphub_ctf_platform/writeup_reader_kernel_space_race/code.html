SECTION 01

Challenge Overview & Source Code Analysis

terminal Original CTF Prompt nc kernel-space.challenges.defcon.org 1337

“Welcome to the sub-millisecond asynchronous arena. The new high-throughput kernel driver speeds up your IPC by utilizing unpinned registered ring buffers. But race conditions in asynchronous workrings leave echoes in the slab. Can you escape the unprivileged user namespace and seize ring-0 dominion?”

During DEF CON 32 Quals, Kernel Space Race was widely considered the most mechanically elegant kernel exploitation challenge. We are provided with a minimal BusyBox Linux environment booted with KASLR, SMEP, SMAP, and KPTI enabled. The target custom kernel module, fastring.ko, hooks directly into the Linux 6.6 async subsystem.

Inspecting the decompiled dispatch table reveals that the module registers a custom file operation handler for IOURING_OP_URING_CMD without acquiring proper refcounts on the backing struct io_buffer_list.

SECTION 02

Vulnerability Discovery (Asynchronous Race Condition)

The core defect lives inside fastring_unregister_buf(). When an unregister request is submitted asynchronously while a background IO submission queue (SQ) thread is processing pending batched reads, a Time-of-Check to Time-of-Use (TOCTOU) race window opens up in the kmalloc-1024 slab cache.

Race Window Execution Timeline Δt ≈ 84 microseconds
SECTION 03

Bypassing KASLR using Leaked Slab Object

Because Linux kernel slab freelist randomization is active, we cannot rely on deterministic pointer prediction. Instead, we immediately spray msg_msg structures containing crafted size descriptors into kmalloc-1024 to overlap the freed buffer list.

SECTION 04

Crafting the Arbitrary Read / Write Primitive

By corrupting the msg_msg->m_ts size attribute, we turn our read primitive into arbitrary address inspection. Once kernel space base address is known, we pivot to crafting an arbitrary write primitive. We have two reliable paths in 6.6 kernels:

Tactic A — Creds Overwrite

commit_creds(&init_cred)

Traversing the current task struct via current_task pointer to locate our process credentials and overwrite euid/gid to zero.

Requires multiple task offsets
Tactic B — Target modprobe_path (Chosen)

modprobe_path Hijack

Writing /tmp/pwn.sh to modprobe_path in the kernel data section, then invoking a file with an invalid ELF header signature.

Cleanest & zero kernel instability
